## 📞 Call Flow (Use This)

**When you get on the call:**

1. **Opening (1 min):** "Thanks for taking the time. I'm interested in what you're building because [specific product detail]. I've been working on the application layer..."

2. **The Story (3 mins):** "I've built four systems: switchboard for booking, social-ops for content approval, priming template for data, agentgraphology for decisions. Each solved a real problem that used to require humans."

3. **The Ask (1 min):** "What's missing is exactly what you're building - orchestration, caching, scaling. I'm not looking to build that myself. I'm looking to join and make sure every builder benefits."

4. **Their Turn (10+ mins):** Listen. Ask questions. Take notes.

5. **Closing (remaining time):** "What does next look like?" (Let them drive the conversation)
