# Scraping (Python)

Standalone Python subproject using [Scrapling](https://github.com/D4Vinci/Scrapling) for web scraping, separate from the Next.js app.

## Setup

```bash
cd scraping
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Usage

```bash
.venv/bin/python your_script.py
```
